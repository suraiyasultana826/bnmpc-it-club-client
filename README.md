# BNMPC IT Club Client

A modern frontend web application for the BNMPC IT Club.

## Live Site

[Visit the website](https://bnmpc-itc.web.app/)

## About BNMPC IT Club

BNMPC IT Club is a student tech community at Bir Shreshtha Noor Mohammad Public College (BNMPC), Peelkhana, Dhaka. Founded in 2017, the club focuses on information technology, programming, digital innovation, workshops, competitions, and student skill development. It also helps students grow through tech-based events and collaborative learning opportunities.

## Online Presence

- **Facebook:** [BNMPC Information Technology Club](https://facebook.com/BNMPCITClub)

## What This Project Is

This repository contains the client-side web interface for the BNMPC IT Club website, designed to present club information, updates, and online presence in a clean and accessible way.

## Tech Stack

- JavaScript
- HTML
- CSS

## Features

- Responsive design
- Simple and clean UI
- Lightweight frontend
- Hosted on Firebase
